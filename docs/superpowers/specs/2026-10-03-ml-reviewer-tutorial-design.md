# 《机器学习审阅者指南》教程设计

日期:2026-10-03
状态:已批准(逐项确认:审阅者视角 / 工程背景入门者 / 仓库内长篇 / 全景 14 章 / 真实生成+提炼陷阱 / 深度联动)
路径:架构级(新子项目,分批交付)

## 1. 定位

- **书名**:中文《机器学习审阅者指南》;英文副题 The Reviewer's Guide to Machine Learning with Python
- **读者**:会 Python、懂基础统计、未系统学过 ML 的工程师——AI 时代 ML 工程的主力
- **核心命题**:AI 写代码的时代,人的价值是定义业务问题、理解原理门槛、审阅 AI 产出。教程教的是"审阅资格"
- **语言**:中文正文,代码与术语英文

## 2. 每章固定叙事结构(五段)

1. **业务问题**:真实场景切入,先讲"什么业务会死在这"
2. **原理门槛**:手写最小实现(50-150 行,纯 Python/numpy),目的不是取代 AI,而是知道 AI 错在哪
3. **AI 工程版**:写作时真实生成的完整实现(附真实提示词),成品经审阅修正
4. **审阅对照**:用 REVIEW-CHECKLISTS.md 问题逐条审两份代码,展示审阅者视角
5. **仓库实战**:用本仓 `scripts/analyze.py` + 历史数据做导航练习;末尾给对应 projects.yaml 类目

## 3. 章节骨架(14 章,四部分)

### Part I 基础与建模(5 章,ch01-05)
1. **引擎而非目录**:AI 时代怎么用这份清单(立场篇)
2. **泄漏**:手写"满分作弊模型"——target leakage 全形态;AI 最常犯的第一错误
3. **切分**:随机/时序/分组——为什么 AI 默认 `train_test_split` 错的比对的多
4. **指标**:AUC ≠ 收入——业务/离线指标翻译;手写混淆矩阵代价分析
5. **表格建模全景**:手写梯度下降 + sklearn 工程版对照

### Part II 数据与领域(4 章,ch06-09)
6. **时序**:rolling-origin、季节基线;AI 预测器如何悄悄用未来
7. **文本**:词频到 embedding;分类、匹配;语言域适配
8. **图像**:增强泄漏、标注质量、分布匹配
9. **特征工程与数据管道**:连接正确性、幂等、漂移

### Part III LLM 时代(4 章,ch10-13)
10. **LLM 访问与微调**:toy attention 手写 → 微调/量化/提示决策树;量化损失实测
11. **RAG**:手写 cosine 检索 → 工程版;检索/生成分离评测;chunking 实验
12. **Agent**:工具边界即安全边界;失败路径、审批、轨迹;"确定性工作流就够了"测试
13. **推理服务**:SLO、批处理/延迟权衡、背压

### Part IV 可信与规模(1 章,ch14)
14. **评测体系与可信 ML**:实验跟踪、可解释性、隐私、对抗——每节一个审阅陷阱;收束到人机分工清单

## 4. 工程安排

- **载体**:`docs/tutorial/chXX-<slug>.md`(中文);代码 `docs/tutorial/code/chXX/`(每章可独立运行:`python chXX_minimal.py`、`python chXX_engineered.py`)
- **AI 素材生产方式**:每章写作时真实生成工程版、真实审阅;典型陷阱提炼自生成过程;成品代码经修正并标注"审阅发现"
- **仓库联动**:
  - 每章末"导航"节:`analyze.py` 实战命令(全部真实可执行)+ 对应类目 ID
  - 审阅对照引用 REVIEW-CHECKLISTS.md 对应节
  - Part I 起手章引用 config/header.md 立场段
- **交付节奏**:分批。**第一批 = Part I(ch01-05)**,完成后交用户审阅,叙事结构验证通过再续写 Part II-IV
- **验收(每章)**:
  1. 手写实现可运行(无第三方依赖,或仅 numpy)
  2. AI 工程版可运行(依赖限 sklearn 等主流库)
  3. 五段结构完整,清单引用闭合
  4. 导航节命令真实可执行
  5. 全书交叉引用(章间互引)有效

## 5. 非目标

- 不做英文版(后续另议)
- 不做交互式 Notebook(后续可加)
- 不覆盖 RL/推荐系统/分布式(审阅门槛在清单中有,教程不展开——14 章已饱和)
- 不替换本仓库已有的任何文档;教程是新增资产

## 7. 风险与对策

- **体量风险**(15-20 万字):分批交付,每批过审再续;单章失控时砍 AI 工程版细节,保审阅对照
- **AI 素材不可复现**:每章附"生成记录"(提示词 + 日期 + 模型名),陷阱清单是提炼物而非逐字记录
- **仓库演进导致联动失效**:导航节命令集中在章末单节,失效时单点修复
